# News App

A responsive news web application built using HTML, CSS, and JavaScript that fetches real-time news using the GNews API.

---

## 🚀 Features

- Fetches latest news using GNews API
- Displays articles in a responsive card layout
- Search functionality to find news by keyword
- Clickable cards to open full articles in a new tab
- Handles missing images with a fallback
- Truncates long titles and descriptions for better UI

---

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Fetch API
- GNews API

---

## ⚙️ How It Works

- On page load, the app fetches top headlines from the GNews API
- Data is received in JSON format and rendered dynamically as news cards
- Users can search for specific topics, triggering a new API request
